## 2. 选择与复制

- 选择位置使用 `blockIndex + utf8Offset`，支持同块和跨块范围。
- 拖选时高亮仅覆盖选中的 UTF-8 文本范围。
- 光标到达视口上下边缘时自动滚动。
- 复制使用系统纯文本剪贴板格式，不写入 HTML 或富文本。
- 段落之间插入换行；代码保留原始换行；表格按行输出，单元格之间使用制表符。
- 新文档打开或切换时清空旧选择。

## 3. 内部锚点

- heading slug 转为小写、空格转连字符、移除常规标点并保留中文。
- 同名标题依次使用 `-1`、`-2` 后缀。
- 支持 `#target-heading` 和百分号编码锚点。
- 锚点索引按需建立，不增加普通文档首屏成本。

## 4. 工作区状态

- 配置文件：用户配置目录下 `liteMark/workspace.ini`。
- 测试可用 `LITEMARK_CONFIG_DIR` 指向隔离目录。
- 启动时只恢复仍存在的文件；缺失文件不会生成无效 Tab。
- 关闭窗口时保存窗口位置、大小、最大化状态、Tab 路径与顺序、当前 Tab、滚动位置和最近文档。
- 最近文档在每次正常打开后移动到首位，重复项去重，最多保存 5 条。

## 6. 目录侧栏

- 未打开时目录栏和三角完全隐藏。
- “查看 > 目录”从隐藏状态打开目录；三角负责展开和收起。
- 展开时侧栏停靠在正文左侧，收起后保留 24 DIP 窄条。
- 展开宽度固定为 260 DIP，全屏时不会按比例扩张。
- 三角绘制在分隔线垂直中部；展开显示左向，收起显示右向。
- 正文使用剩余宽度重新排版，目录不会覆盖文字。
- 打开或关闭侧栏时记录当前阅读块和块内偏移，重排后恢复阅读位置。
- 当前文档切换或解析完成后自动更新标题列表。
- 点击标题复用文内锚点跳转逻辑；点击左向三角即可收起。
- 目录隐藏、展开、收起三态写入工作区，重启后恢复。
- 目录列表使用虚拟列表，只绘制可见标题。
- 滚轮事件在目录内部累计处理，每档移动 3 行，不滚动正文。

## 7. 菜单与文档搜索

- 移除“编辑”顶级菜单。
- 文件菜单不再显示“关闭当前 Tab”。
- 查看菜单不再显示“上一个 Tab”和“下一个 Tab”。
- 对应快捷键仍保留，Tab 关闭按钮仍在。
- `Ctrl+F` 打开临时查找栏。
- 搜索后台执行，当前命中高亮并自动进入视口。
- “帮助”菜单提供使用说明和关于 liteMark。
- 版本统一来自 CMake `1.0.0`，安装器、EXE 文件属性和关于对话框使用同一版本源。
