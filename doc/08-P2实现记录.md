## 2. 选择与复制

- 选择位置使用 `blockIndex + utf8Offset`，支持同块和跨块范围。
- 拖选时高亮仅覆盖选中的 UTF-8 文本范围。
- 光标到达视口上下边缘时自动滚动。
- 复制使用系统纯文本剪贴板格式，不写入 HTML 或富文本。
- 段落之间插入换行；代码保留原始换行；表格按行输出，单元格之间使用制表符。
- 新文档打开或切换时清空旧选择。

## 3. 内部锚点

- heading slug 转为小写、空格转连字符、移除常规标点并保留中文。
- 同名标题依次使用 `-1`、`-2` 后缀。
- 支持 `#target-heading` 和百分号编码锚点。
- 锚点索引按需建立，不增加普通文档首屏成本。

## 4. 工作区状态

- 配置文件：用户配置目录下 `liteMark/workspace.ini`。
- 测试可用 `LITEMARK_CONFIG_DIR` 指向隔离目录。
- 启动时只恢复仍存在的文件；缺失文件不会生成无效 Tab。
- 关闭窗口时保存窗口位置、大小、最大化状态、Tab 路径与顺序、当前 Tab、滚动位置和最近文档。
- 最近文档在每次正常打开后移动到首位，重复项去重，最多保存 5 条。
