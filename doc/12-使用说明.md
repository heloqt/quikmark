# QuikMark 使用说明

## 安装

Windows：

- 当前安装器默认安装到当前用户目录，不需要管理员权限。
- 开始菜单快捷方式会始终创建。
- 安装目录和开始菜单中会包含本使用说明。
- “桌面快捷方式”和“关联 Markdown 文件”默认勾选，可以在安装组件页取消。
- 取消文件关联或卸载时，会尽量恢复安装前的文件关联。
- 完成页可以勾选“运行 QuikMark”，默认不自动运行。

Linux：

- `.deb` 推荐使用 `sudo apt install ./quikmark_1.2.0_amd64.deb` 安装。
- AppImage 需要先执行 `chmod +x QuikMark-1.2.0-x86_64.AppImage`，然后直接运行。
- 若系统提示缺少 FUSE，可使用
  `APPIMAGE_EXTRACT_AND_RUN=1 ./QuikMark-1.2.0-x86_64.AppImage`。
- AppImage 不会自动修改默认打开方式；可通过“文件 > 注册文件关联...”启用。

## 1. 打开文档

可以通过以下方式打开 Markdown 文件：

- “文件 > 打开...”
- 把一个或多个 `.md` / `.markdown` 文件拖入窗口
- 在资源管理器中用 QuikMark 打开已关联的 Markdown 文件

同一窗口使用多个 Tab 管理文档。再次打开已经打开的文件时，会切换到原来的 Tab。

## 2. 菜单

### 文件

| 菜单项 | 作用 |
|---|---|
| 打开... | 选择一个或多个 Markdown 文件 |
| 最近打开 | 打开最近使用的文档，最多保留 5 条 |
| 重新加载 | 重新读取当前文档 |
| 注册文件关联... | 把 QuikMark 注册为 `.md` / `.markdown` 打开方式 |
| 退出 | 关闭 QuikMark |

### 查看

| 菜单项 | 作用 |
|---|---|
| 查找... | 打开临时查找栏 |
| 外观 | 跟随系统、浅色或深色 |
| 语言 | 跟随系统语言、English 或简体中文 |
| 目录 | 勾选后打开目录；取消后完全隐藏 |

### 帮助

| 菜单项 | 作用 |
|---|---|
| 使用说明 | 打开随程序安装的使用说明，快捷键 `F1` |
| 关于 QuikMark | 显示当前版本、构建类型和 wxWidgets 版本 |

“编辑”菜单、文件菜单中的“关闭当前 Tab”、查看菜单中的“上一个/下一个 Tab”为保持界面精简而不显示，对应快捷键仍可使用。

首次启动时界面语言跟随系统。可以在“查看 > 语言”中切换语言，选择会保存到配置文件。菜单、空白页、查找栏、提示框和帮助文档会同步切换；使用说明根据当前语言打开 `Usage.md` 或 `使用说明.md`。

## 3. 快捷键

### 文件与 Tab

| 快捷键 | 作用 |
|---|---|
| `Ctrl+O` | 打开文件 |
| `Ctrl+R` | 重新加载当前文档 |
| `Ctrl+W` | 关闭当前 Tab |
| `Ctrl+Tab` | 切换到下一个 Tab |
| `Ctrl+Shift+Tab` | 切换到上一个 Tab |

### 选择与复制

| 快捷键 | 作用 |
|---|---|
| 鼠标拖动 | 选择一个或多个块中的文字 |
| 表格内鼠标拖动 | 选择单元格中的文字，也可跨单元格连续选择 |
| `Ctrl+A` | 全选当前文档 |
| `Ctrl+C` | 将选择内容复制为纯文本 |

在表格中右键单击并选择“复制整个表格”，会同时复制：

- HTML 表格：直接粘贴到 Word 后保持行列结构。
- TSV 纯文本：粘贴到 Excel、WPS 或纯文本编辑器，单元格使用制表符分隔。

整表复制不会改变当前文字选区；普通 `Ctrl+C` 仍只复制当前选择内容。

### 查找

| 快捷键 | 作用 |
|---|---|
| `Ctrl+F` | 打开查找栏 |
| `F1` | 在 QuikMark 中打开使用说明 Tab |
| `Enter` | 跳到下一个匹配 |
| `F3` | 跳到下一个匹配 |
| `Shift+Enter` | 跳到上一个匹配 |
| `Shift+F3` | 跳到上一个匹配 |
| `Esc` | 关闭查找栏并清除匹配高亮 |

查找支持英文大小写不敏感匹配和中文原文匹配。切换文档后，会按当前查询重新搜索。

### 显示

| 操作 | 作用 |
|---|---|
| `Ctrl+鼠标滚轮` | 调整正文字体大小 |
| 鼠标滚轮 | 滚动文档 |
| `Shift+鼠标滚轮` | 在可横向滚动的表格内横向滚动 |

## 4. 目录侧栏

- 未打开目录时，目录栏和三角都不显示。
- 通过“查看 > 目录”打开目录。
- 点击分隔线中部的左向三角收起为窄条，收起后点击右向三角重新展开。
- 再次取消“查看 > 目录”会完全隐藏目录栏。
- 勾选时侧栏常驻，正文会使用剩余宽度重新排版。
- 点击目录项会跳转到对应标题，侧栏保持打开。
- 目录的隐藏、展开和收起状态会随工作区保存，重启后恢复。

## 5. 搜索

- 输入内容后自动开始搜索，不需要按回车。
- 所有匹配使用浅色背景，当前匹配使用更明显的背景。
- 查找栏只在需要时显示，关闭后不占用正文空间。
- 单个查询最多显示 10000 个结果，超出时会提示“已截断”。

## 6. 阅读与显示

- 支持标题、段落、粗体、斜体、删除线、列表、任务列表、引用、代码块、表格、图片、链接和基础 Mermaid flowchart。
- 本地图片以及 HTTP/HTTPS 网络图片会异步加载。
- 点击 `http`、`https`、`mailto` 链接会交给系统默认应用打开。
- 不支持的 Markdown 或 Mermaid 内容优先显示原始代码。
- 浅色和深色主题都可以在“查看 > 外观”中切换，选择会自动保存。

## 7. 文件变化与阅读状态

- 当前文档被外部修改时，会显示非模态提示条。
- 可以选择“重新加载”或“稍后”。
- 非当前 Tab 被修改时，只会在 Tab 上显示变化标记。
- 关闭 QuikMark 时保存窗口位置、Tab 顺序、当前 Tab、滚动位置和目录三态。
- 下次启动时恢复仍然存在的文档。

## 8. 当前版本说明

- QuikMark 是只读 Markdown 阅读器，不提供编辑和保存功能。
- 首次从 liteMark 升级时，会迁移工作区、最近文档和主题设置。
- 同一时间只有一个主窗口；再次启动会把文件转发到已有窗口。
- 当前尚未提供 PDF 导出。
- 支持 UTF-8 和 UTF-8 BOM；其他编码会显示错误提示。
