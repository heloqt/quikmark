# P1 性能测试记录

## 1. 测试结论

测试日期：2026-10-22

本轮在 AMD Ryzen 7 8845HS 本机上完成常规文档和 10 MB 文档测试。常规文档的冷启动、热打开、Tab 切换和滚动均满足当前 P1 门槛；10 MB 文档滚动满足门槛，冷启动挑战目标未达到，Tab 切换 P95 超过 50 ms。

| 场景 | 样本数 | P50 | P95 | 最大值 | 门槛 | 结果 |
|---|---:|---:|---:|---:|---:|---|
| 约 150 KB 冷启动首屏 | 20 | 398.625 ms | 438.533 ms | 486.356 ms | P95 <= 500 ms | 通过 |
| 约 150 KB 热打开首屏 | 20 | 42.893 ms | 62.500 ms | 108.299 ms | P95 <= 300 ms | 通过 |
| 约 150 KB Tab 切换 | 40 | 10.897 ms | 15.751 ms | 16.756 ms | P95 <= 50 ms | 通过 |
| 10 MB 冷启动首屏 | 5 | 871.735 ms | 967.589 ms | 967.589 ms | 挑战目标 <= 300 ms | 未达到 |
| 10 MB 热打开首屏 | 5 | 504.580 ms | 526.909 ms | 526.909 ms | 仅记录 | 完成 |
| 10 MB Tab 切换 | 20 | 69.311 ms | 87.594 ms | 88.696 ms | P95 <= 50 ms | 未通过 |
| 10 MB 连续滚动 | 30 | 5.206 ms | 7.040 ms | 7.843 ms | P95 <= 16.7 ms，单次 <= 50 ms | 通过 |

常规文档的最终判定为 **通过**。10 MB 冷启动按已确认需求只作为挑战项，不参与验收判定；10 MB Tab 切换未达到 50 ms 门槛，应作为后续大文档性能优化项。

## 3. 测试文件

- 常规样本：20 份约 150 KB Markdown，单份包含中英文、标题、段落、强调、链接、行内代码、列表、引用、代码块和表格。
- 大文档样本：5 份 10,813,440 字节 Markdown，内容结构相同。
- 测试文件由脚本在 `build\perf-fixtures` 和 `build\perf-large-fixtures` 中生成，不写入源码目录。

## 4. 测量口径

- 冷启动：从启动进程开始，到目标文档首个可读视口完成应用侧绘制。
- 热打开：主实例已运行，第二实例通过命名管道转发文件路径；从主实例开始解析到首个可读视口完成绘制。
- Tab 切换：从 `Ctrl+Tab` 操作开始，到目标 Tab 的首帧完成绘制。
- 滚动：向 10 MB 文档发送 30 次标准鼠标滚轮消息，从滚轮事件处理开始到对应帧完成绘制。
- 性能事件只在设置 `LITEMARK_PERF_TRACE` 时写入 CSV，正常使用不受影响。
- 计时终点为应用侧完成绘制，不包含 Windows 桌面合成器的额外显示延迟。

原始事件写入 `build\perf-*.csv`，结构化结果写入 `build\performance-results.json`。

## 5. 复现方式

先关闭所有 liteMark 实例，然后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\benchmark.ps1 -Samples 20 -LargeSamples 5
```

脚本会重新构建测试文件、运行四类性能采样、校验样本数量并输出 JSON。完整运行约需 1 分钟。

## 6. 稳定性观察

常规冷启动 P95 在三次 20 样本正式运行中分别约为 501.1 ms、439.5 ms 和 438.5 ms。首次结果刚好越过 500 ms，后两次通过，说明该指标距离门槛较近，且受系统启动调度和后台负载影响。

后续性能验收应在相同机器、相同电源和显示设置下重复运行，并记录每次 P95，不能只依赖单次结果。10 MB 冷启动和切换的当前性能差距较大，属于真实优化空间，不是测量误差。
