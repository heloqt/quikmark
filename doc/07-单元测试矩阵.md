# 单元测试矩阵

## 1. 运行方式

运行全部单元测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

同时运行滚动状态 UI 回归：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass `
  -File .\scripts\test.ps1 -Integration
```

当前 Windows 共有 18 个 CTest 入口，Linux 共有 20 个入口。单元测试覆盖
解析、布局、文档状态、Linux 平台服务和彩色 emoji 绘制。另有滚动、选择、
锚点、查询、剪贴板和工作区恢复 UI 集成回归。

## 4. 分层原则

- 单元测试验证确定性规则，不访问网络、系统浏览器、剪贴板或用户配置文件。
- 文件系统监听、单实例 IPC、真实浏览器启动、图片下载和 DPI 绘制通过集成或视觉测试验证。
- 性能门槛由 `scripts/benchmark.ps1` 验证，不使用耗时极短且波动大的单元测试代替。
- 跨块选择、真实剪贴板、标题跳转和重启恢复由 `p2-feature-regression.ps1` 做 UI 集成验证。
- 新增纯逻辑时，应优先提取为无 UI 依赖的组件，并加入本矩阵和 CTest。
